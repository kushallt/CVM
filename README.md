# CVM — Custom Virtual Machine Language

CVM is a lightweight interpreted programming language built from scratch in C++17. It implements a complete execution pipeline consisting of a hand-written lexer, a recursive descent parser that generates an Abstract Syntax Tree (AST), a bytecode compiler based on the Visitor pattern, and a stack-based virtual machine that executes the generated bytecode.

---

## Features

- Hand-written lexical analyzer
- Recursive descent parser
- AST-based compilation pipeline
- Visitor-pattern bytecode compiler
- Stack-based virtual machine
- Open-addressing hash table for global variables
- Dynamic memory management with custom growable arrays
- Support for:
  - Variables and assignments
  - Arithmetic expressions
  - Comparisons and logical negation
  - Conditional execution (`if`)
  - Loops (`while`)
  - User input
  - Printing values and strings
  - Single-line comments

---

## Example Program

```cvm
// Read a number from the user
x = input "Enter a number: ";

// Conditionals
if (x > 10) print "x is more than 10\n";
if (x < 10) print "x is less than 10\n";
if (x == 10) print "x is equal to 10\n";

// Loop
let count = 0;
while (count < x)
    count = count + 1;

print "Program Complete.";
```

## Architecture

### Lexer

The lexer converts source text into a stream of tokens.

Supported token categories include:

- Keywords (`if`, `while`, `let`, `print`, `input`)
- Operators (`+`, `-`, `*`, `/`, `==`, `!=`, `<`, `>`, `!`)
- Identifiers
- Numeric literals
- Structural symbols (`(`, `)`, `;`)

Each token stores:

```cpp
struct Token {
    TokenType type;
    std::string val;
    int line;
};
```

---

### Parser & AST

The parser is implemented as a recursive descent parser that converts tokens into an Abstract Syntax Tree.

Key AST node types:

| Node | Purpose |
|--------|----------|
| Literal | Numeric/Boolean constants |
| Variable | Variable access |
| Assignment | Variable update |
| Binary | Binary expressions |
| Unary | Unary expressions |
| IfStmt | Conditional execution |
| WhileStmt | Loop execution |
| PrintStmt | Output |
| InputStmt | User input |
| DeclStmt | Variable declaration |

All AST nodes support the Visitor pattern:

```cpp
virtual void accept(Visitor& v) = 0;
```

---

### Bytecode Compiler

The compiler traverses the AST and emits bytecode instructions into a `Chunk`.

Core opcodes include:

```text
Op_Constant
Op_SetGlobal
Op_GetGlobal
Op_Add
Op_Sub
Op_Mul
Op_Div
Op_Equality
Op_Lesser
Op_Greater
Op_Not
Op_Print
Op_Input
Op_JumpIfFalse
Op_Jump
Op_Return
```

Control flow (`if`, `while`) is implemented using jump instructions with back-patching.

---

### Virtual Machine

The VM executes bytecode using a stack-based architecture.

Core components:

```cpp
uint8_t* ip;
Value stack[256];
Value* stackTop;
```

Execution occurs through a continuous dispatch loop:

```cpp
for (;;) {
    OpCode instruction = READ_BYTE();
    switch (instruction) {
        ...
    }
}
```

The VM supports:

- Arithmetic operations
- Boolean operations
- Variable lookup
- Variable assignment
- Conditional jumps
- Loop execution
- User input/output

---

## Variable Storage

Global variables are stored in a custom open-addressing hash table.

### Characteristics

- FNV-1a hashing
- Linear probing collision resolution
- Tombstone-based deletion
- Automatic resizing
- Load factor threshold of 0.75

Lookup complexity is approximately O(1) on average.

---

## Memory Management

Dynamic structures use custom growable arrays backed by `realloc`.

```cpp
#define GROW_ARRAY(type, ptr, oldcount, newcount)
#define FREE_ARRAY(type, ptr, oldcount)
```

Used by:

- Bytecode chunks
- Constant pools
- Hash tables
- Internal VM structures

---

## Value System

All runtime values are represented using a tagged union.

```cpp
typedef struct {
    ValueType type;

    union {
        bool boolean;
        double number;
        ObjString* str;
    } as;
} Value;
```

Supported value types:

- Numbers
- Booleans
- Strings
- Nil

## Debugging Tools

### Token Stream Dump

```cpp
for (auto& t : LexedTokens)
    std::cout << int(t.type) << " " << t.val << std::endl;
```

### AST Printer

```cpp
Printer printer;

for (auto& stmt : FinalAST)
    stmt->accept(printer);
```

### Bytecode Disassembly

```cpp
chunk.disassembleChunk("test chunk");
```

### Raw Bytecode Dump

```cpp
for (int i = 0; i < chunk.count; i++)
    std::cout << (int)chunk.code[i] << std::endl;
```
